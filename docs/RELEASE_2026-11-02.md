# Bilingual catalogue release — 2 November 2026

This release adds Simplified Chinese/English pages, mobile usability improvements, 12 additional profiles and locally served game illustrations. Deployment is pending; this record describes the checked source branch.

## Implemented

- `/en` and `/zh`, browser/saved language selection, translated UI and metadata. A language switch keeps the current request, edited criteria, exclusions, comparisons and feedback draft, without submitting a provider request.
- 24 canonical profiles, bilingual public copy and Chinese title aliases. Matching uses the same canonical facts, IDs and source links in both languages; unknown and provisional information stays explicit.
- Phone criteria controls use 16px text and at least 44px height. Navigation, cards, dialogs and the fixed comparison tray adapt to narrow screens. Wide comparison tables scroll inside their own labelled region.
- Two licensed screenshots with source/credit/licence links; the other 22 cards have original title graphics. The Wesnoth image is explicitly a historical 2015 illustration. See [artwork scope and notices](ARTWORK.md).

## Verification

- All 118 Node tests pass, including bilingual matching invariance, catalogue/evidence alignment, unknown-value handling and expanded request-envelope checks.
- Next.js production build, its TypeScript stage and standalone preparation pass. This Windows checkout shares a local dependency folder; the local standalone output retains that link and is not a portable Linux export. Docker installs dependencies fresh on Linux.
- Packaged server returns HTTP 200 with Chinese HTML language/title metadata. Its browser view loads the Chinese catalogue and local screenshot correctly.
- Browser checks cover state retention while switching languages, manual criteria, game exclusion, Chinese alias lookup, profile/source display, comparison, and retention of an unsubmitted feedback draft.
- English and Chinese page widths were checked at 320, 360, 390 and 430 CSS pixels, without page-level horizontal overflow. At 320/360px all four criterion selects computed to 16px text and 44px height. A 320px comparison dialog kept its wide table within a scrolling region.

These are desktop-browser viewport checks, not physical Android/iOS or cross-browser results. No new live AI generation or feedback submission was used. Existing provider/security/quota tests passed; the original cumulative US$10 allowance and server ledger were not changed. The live-server upgrade must preserve its existing SQLite volume and private settings, with no repeat ledger import.

## Remaining scope

Real-device feedback, broader interpretation quality, independent source review and more permitted artwork remain useful follow-up work. This catalogue does not establish overall game balance, depth or authenticity. Pricing/FX references still need their existing review before 5 November 2026; this release does not extend that guard.
