# Contributing

Tactical Atlas is an early experiment in game discovery. Small, concrete contributions are welcome.

1. Run the project using the README. Work on a focused branch and describe the problem your change addresses.
2. For a profile, add original paraphrases and public source URLs, locations, dates, edition scope and limits. Every known matching facet needs a resolvable evidence ID. Unknown is different from false. Explain subjective judgments through concrete mechanics.
3. For search behavior, include a short request, the intended interpretation and why it is useful. Preserve negation, exclusions, hard/preferred language and unhandled requirements.
4. Run the checks relevant to the change. Changes to matching, interpretation or quotas need meaningful edge-case coverage; prose-only edits do not need mirrored tests.
5. Submit a concise change description with actual validation and remaining limits. Never include keys, local environment files, private research, user requests or third-party media archives.

Suggested first tasks:

- Add one game that broadens a currently weak catalogue contrast.
- Improve one uncertainty explanation with a before/after example.
- Provide an English or Chinese search case that the current vocabulary handles poorly.

For an unsuitable result, describe the expected behavior and the public profile involved. Share personal search text only if you choose to; do not include sensitive information. Use [GitHub issues](https://github.com/arcueidbrunnstadt/tactical-atlas/issues) for public discussion, bug reports, search cases and profile requests. You can also send a private note through the website's feedback form without a GitHub account. The form does not provide a reply channel; use an issue if you want a public follow-up.
